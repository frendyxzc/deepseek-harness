- 每个 util 子包统一采用 src/lib 双目录结构：源码在 src，tsdown 输出到 lib，并自动生成 types/ 声明与 invariant.js 运行时断言。
- 每个包通过顶层 `index.ts` 仅 re-export 核心函数与类型，将实现细节放在同目录的子模块（如 native-command 的 runner.ts、path-opener.ts）。
- 公共 API 使用 JSDoc `@module` 注释标注包名（如 `@deepseek-ai/dsh-util-crypto`），并在 README.i18n.yaml 中提供多语言说明。
- typert 的 protocol 包通过 `declare const` 唯一符号（LOOKUP_HOST、LOOKUP_WIRE、CONTEXT_WIRE）实现类型级关联，避免运行时开销。
- typert/registry 通过 `declare module '@deepseek-ai/dsh-typert-protocol'` 的 module augmentation 向协议契约注入具体实现方法，保持协议与实现的松耦合。
- util 包对跨平台原语做统一封装（如 crypto 用 `globalThis.crypto.getRandomValues` 替代 `crypto.randomUUID`），以屏蔽浏览器/Node 差异。
