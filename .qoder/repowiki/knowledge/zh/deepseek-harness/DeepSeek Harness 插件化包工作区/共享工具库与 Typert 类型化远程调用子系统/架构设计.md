本模块由两个并列的 package-group 组成：

- `packages/util/`：一组相互独立的零依赖工具包（atomic-write、brand、crypto、home-paths、launch-environment、native-command、output-retention、timeout、workspace-path），每个子目录都是一个自包含 npm 包，遵循统一的 src/lib 双结构——`src/*.ts` 为 TypeScript 源码，经 tsdown 编译到同级 `lib/` 并附带 `types/` 声明与 `invariant.js` 运行时断言；包之间不互相引用，仅通过各自 `package.json` 暴露最小 API。
- `packages/typert/`：围绕「类型即契约」的远程调用子系统，按职责拆分为四个协作包：`protocol` 定义跨 Host/Client 的装饰器、wire descriptor、codec 与 provider 契约（纯类型 + 极小运行时）；`generator` 在构建期分析 workspace 中的类型声明，产出 compiler-independent model、反射与 Remote 描述符（analyzer → model → emitter/renderer/workspace 流水线）；`registry` 在运行期保存生成的包反射与 Zod schema，并通过 module augmentation 向 `@deepseek-ai/dsh-typert-protocol` 注入 `TypertRegistryContract`；`loader` 作为插件把已生成的 artifacts 自动注册进 registry。依赖方向严格单向：loader → registry → protocol，generator 仅在构建期消费业务包类型，不与 runtime 耦合。

所有包均使用 tsdown 构建，测试位于各包 `tests/` 下，README 采用 i18n.yaml + README.md/README.zh.md 多语言文档结构。
