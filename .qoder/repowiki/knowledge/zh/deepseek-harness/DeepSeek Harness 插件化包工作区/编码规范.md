- 每个包只属于一个能力组，并在自身 README 中说明用途、配置、扩展点与 Model Experience。
- 可插拔能力统一采用 Service Definition（seam）/ Service Provider / Consumer 三角色分离，Consumer 仅依赖 seam 而非具体实现。
- Host 与 Client 之间的远程调用通过 Typert 在构建期从类型定义生成，禁止手写 JSON-RPC 消息结构。
- 跨包共享状态通过 ctx 键注册与读取（如 LLM provider、凭据解析器、设置服务），避免显式参数传递。
- 包间依赖方向受 CI 模块图约束，新增依赖需在 `docs/module-graph.md` 变更中体现。
