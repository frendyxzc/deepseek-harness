本模块由两个独立但互补的子包组成：

- `llm-retry`（`@deepseek-ai/dsh-llm-retry`）：以 Cordis 插件形式暴露 `apply(ctx, config)`，监听 `agent/request-error` 事件并根据每个 Provider 配置的 `ResolvedRetryPolicy`（`normal`/`always` 两种模式）执行指数退避 + jitter 重试；通过 `AbortSignal.any` 融合 session abort 与插件生命周期信号，使用 `session.append('llm/retry'|'llm/retry-started')` 持久化每次重试调度与开始，并通过 `policyKey` 去重同一 turn/step/provider 下的重复重试计数。
- `token-meter`（`@deepseek-ai/dsh-token-meter`）：实现为继承 `Service` 的 `TokenMeter`，维护 per-session 的 `ReplayState`（WeakMap），在构造时注册到可选的 `sessionProjections` 上下文，订阅 `session/event` 增量同步；核心流程是 `measure(session, requestHeader?)` → `_sync` 消费 durable tail → `surface-fold.ts` 的 plan/commit 两阶段折叠出带 route 定价的 `MeterSurfaceNode[]` → 结合上次成功调用的 `MeasurementAnchor` 选择 usage/estimated/none 基线并计算 `totalTokens`。

依赖方向：`token-meter` 依赖 `llm-retry`（peerDependency），两者均依赖 `@deepseek-ai/cordis`、`@deepseek-ai/dsh-session`、`@deepseek-ai/dsh-llm`；`token-meter` 通过 `BlockAssembler` 从 `assistant/chunk` 源 seq 重建 provider 输出以估算 assistant tokens，并通过 `route-pricing.ts` 按 `config.provider/model` 查询 image 视觉 token 定价。
