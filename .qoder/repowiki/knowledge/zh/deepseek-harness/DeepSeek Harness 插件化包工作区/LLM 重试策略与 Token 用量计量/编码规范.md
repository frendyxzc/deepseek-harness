- 插件/服务通过导出 `name`、`inject`、`Config`（schemastery schema）和 `apply`/构造函数来接入 Cordis 上下文，并在内部调用 `validateConfig` 拒绝未知键。
- 对外暴露的类型集中在 `src/types.ts`，并通过 `declare module` 扩展 `SessionEventMap` 或 `Context` 接口以注入新的事件类型与上下文属性。
- 可重放的状态变更采用 plan/commit 两阶段模式：先无副作用地生成 `Plan`，再对原数组原地 `splice/push` 提交，确保抛错不会留下半应用状态。
- 重试与计量均通过 `AbortSignal`（含 `AbortController` 生命周期）管理异步等待的可取消性，并在 dispose/effect 中 `Promise.allSettled` 清理活跃操作。
- 所有面向用户的测量结果通过 `structuredClone` + `deepFreeze` 返回深度不可变快照，避免下游误修改 replay state。
- Provider 路由信息（provider/model/config）作为 key 参与去重与定价决策，例如 `retryPolicyKey` 与 `_routeImagePricing` 均基于 header 中的 config 字段派生。
