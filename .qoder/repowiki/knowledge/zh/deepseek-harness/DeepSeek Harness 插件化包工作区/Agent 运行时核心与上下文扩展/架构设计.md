本模块由 `packages/core` 与 `packages/context` 两大子树组成，围绕 Cordis 服务容器构建可插拔的 Agent 运行时。

- `core/agent`：定义 `AgentRegistry`（`ctx.agents`），维护 Agent 生命周期表、`AsyncLocalStorage` 驱动的发起者链（`withInitiator`/`withoutInitiator`），并通过 `setFactory` 将创建/恢复委托给 `dsh-agent-loop`，实现接口与实现的解耦。
- `core/session`：以 `SessionStore` + `Session` 实现事件溯源会话——不可变追加日志、`SurfaceManager` 维护有序消息面、`deriveMessages` 缓存 LLM 消息历史；通过 `prepare → enter → announce` 三段式事务保证发布回滚安全，并以 `session/event`、`session/flush` 暴露持久化插件钩子。
- `core/tools`：`ToolRuntime` 基于 `ScopedLayers` 维护按作用域叠加的工具注册、限制与守卫，提供 `pre-execute / execute / post-execute / result` 瀑布管线，支持 native/ptc/both 三种模型呈现模式，并内置 `run_code` PTC 传输。
- `core/agent-loop`：具体 `AgentLoop` 实现 `AgentFactory`，编排 `ReactLoopAgent` 启动、会话准备、setup 事务与 ordered teardown，并通过 `FactoryOwnership` 统一跟踪活跃 Agent 与配置启动任务。
- `core/scope`：底层作用域原语，用 `WeakMap` 维护 `ScopeKey` 父子链，`scopeTarget` 生成仅用于事件路由的 Scoped 载体，使 agent-scoped 监听器只接收同作用域或后代事件。
- `core/{session,system-prompt,tools,agent-default-model,agent-tool-presentation}`：各自作为独立 Cordis 插件，通过 `declare module '@deepseek-ai/cordis'` 向 `Context` 注入 `sessions`、`tools`、`systemPrompt` 等行。
- `context/*`：面向 Agent 的上下文增强插件——`agent-instructions` 监听文件变更并合成 baseline 指令到 inbox；`file-reference`/`file-reference-local` 解析 `@file:` 引用；`session-reference` 跨进程投影 Session；`time-context`/`tmux-context` 注入时间与终端环境。

依赖方向自下而上：`scope` → `session` → `agent` → `tools` → `agent-loop` → `context/*`；各包之间通过 Cordis `Service` 与 `Events` 契约交互，不直接耦合实现。
