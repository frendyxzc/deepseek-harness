- 通过 `declare module '@deepseek-ai/cordis'` 在 `Context` 上扩展 `services`（如 `agents`、`sessions`、`tools`）并在构造函数中 `super(ctx, 'name')` 注册为 Cordis Service。
- 对外暴露的事件类型使用 `declare module '@deepseek-ai/cordis' { interface Events { ... } }` 声明，并在 JSDoc 中标注 `@mode emit/waterfall` 以区分同步通知与可中断瀑布。
- 所有跨边界传入的数据在持久化/日志前调用 `snapshotJsonValue` 做 lossless JSON 快照，再用 `deepFreeze` 深冻结，确保事件日志不可变。
- 生命周期采用 `prepare → enter → announce` 三段式：先构造对象，再通过 `enter` 安装 detach 能力，最后 `announce` 触发创建事件，失败时 detach 自动回滚。
- 作用域路由统一通过 `scopeTarget(subject, scopeKey)` 生成带过滤器的 Scoped 载体，配合 `scopeOf`/`bindScopeParent` 维护父子链，使监听器按作用域继承向上匹配。
- 每个子包遵循 `src/index.ts` 导出公共 API、`src/invariant.ts` 存放运行时不变量检查、`tests/*.spec.ts` 对应源码结构的单测布局，并使用 `tsdown` 构建到 `lib/`。
