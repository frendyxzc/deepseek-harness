- 插件根 `index.ts` 统一导出空 `apply(): void` 作为宿主桩，真实逻辑放在 `src/client/` 并通过 `package.json` 的 `exports['./client']` 暴露。
- 通过 `declare module '@deepseek-ai/dsh-client-ui-slots'` 扩展 `LocaleNamespaceMap`，将本包的 locale key 命名空间（如 `settings.models`、`settings.pluginInventory`）注册到宿主类型系统。
- 组件以函数式 React 组件形式暴露，并通过 `Injected` 接口 + `Props = Partial<Injected>` 的模式定义 slot 注入的依赖（如 `MemorySectionInjected`、`PluginInventorySettingsTabInjected`）。
- 跨层数据流统一使用 `createSnapshotStore` + `store.update` 更新快照，并通过 `hooks: { snapshot }` 把 store 透传给 slot 消费者，避免重复状态。
- 对外部错误一律通过 `messageOf(error)` 或 `error instanceof Error ? error.message : String(error)` 归一化为字符串后写入快照的 `error`/`credentialError` 字段。
- 通过 `ctx.effect` 注册副作用并在返回的清理函数中调用所有监听器的 `dispose`，确保插件卸载时释放事件订阅。
