三个包遵循同一插件形态：根 `index.ts` 导出空 `apply()` 作为宿主侧桩，真正的浏览器逻辑集中在 `src/client/`，并通过 `package.json` 的 `dsh.client.inject` 声明依赖 `@deepseek-ai/dsh-client-ui-settings`、`locale`、`api-remotes` 等宿主能力。

- `ui-settings-models` 是核心：`client/index.ts` 在 `apply(ctx)` 中注册 `settings.section`（id=`models`）与两个 `settings.onboarding` 插槽（welcome-notice、deepseek-official），通过 `ctx.slots.register` 注入 React 组件；使用 `createSnapshotStore` 维护 `ModelsSettingsState`，由 `ModelsSettingsStore` 并发拉取 `llm.listProviders`、`llm.listConfigurableProviders` 与共享镜像 `describe`，再批量 `credentials.describe` 补齐凭据信息，并通过 `ctx.remote.$on(...)` 订阅 document-updated / reference-updated / adapters-updated 事件实现无轮询刷新。
- `ui-settings-memory` 仅暴露一个 `MemorySection` 组件，根据当前页面是否 loopback 拼接本地 8123 端口 URL 并在新标签页打开腾讯 DB-Agent-Memory 控制台。
- `ui-settings-plugin-inventory` 暴露 `PluginInventorySettingsTab`，通过注入的 `list()` Remote 读取 Loader 的 `PluginInventorySnapshot`，提供搜索、展开详情与状态指示。

依赖方向单向向外：各插件通过 `@deepseek-ai/dsh-api-remotes/client` 的 `ClientRemote` 子面（`credentials`、`llm`、`remote.settings`）与宿主通信，不直接引用其他设置插件，彼此解耦。
