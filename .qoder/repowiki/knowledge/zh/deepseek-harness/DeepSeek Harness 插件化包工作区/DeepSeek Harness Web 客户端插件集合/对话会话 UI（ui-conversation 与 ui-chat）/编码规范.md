- 每个包通过顶层 `index.ts` 仅导出 settings 命名空间与 `apply(ctx)` 钩子，真正的客户端 API 从 `src/client/index.ts` 统一 re-export。
- 运行时装配集中在 `src/client/apply.ts`，以 `inject = [...]` 声明所需服务，再通过 `ctx.slots.inject(name, () => ctx.slots.register(...))` 将 React 组件注册到命名槽位。
- 业务节点定义采用“每个节点一个文件 + 同名 `registerXxxConversationNode` 函数”的模式，并由 `conversation-nodes/register.ts` 集中调用完成注册。
- 跨包契约集中在 `client/contract/` 目录下，UI 实现通过 `import type` 引入契约类型，避免循环依赖。
- Locale 通过 `ctx.locale.register(NS, { zh, en })` 注册字典，并使用 `ctx.locale.bind(NS)` 获取翻译函数，键名集中在 `locale.ts` / `locales.ts` 中声明。
- 对外暴露的类型通过 `declare module './contract/*.ts'` 进行声明合并（如 `ChatNodeDataMap`、`LocaleNamespaceMap`），使第三方插件可扩展接口而不修改源码。
