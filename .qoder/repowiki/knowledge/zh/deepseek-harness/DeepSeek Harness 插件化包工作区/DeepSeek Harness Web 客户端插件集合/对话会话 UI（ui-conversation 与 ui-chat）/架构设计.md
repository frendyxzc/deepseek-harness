本模块由两个相互协作的包组成：`ui-conversation` 是目标无关的核心层，`ui-chat` 是基于该核心实现的 Chat 目标插件。

- `ui-conversation` 通过 `src/client/apply.ts` 在 Cordis 上下文中注册根槽位 `conversation`、`conversation.session`、`conversation.session.header`、`conversation.composer` 等，并暴露 `UiConversation`、`ConversationController`、`ConversationNodeAssembler`、`ConversationDefinitionRegistry`、`ConversationEventRegistry`、`ConversationViewRegistry`、`ConversationLocationIndex` 等核心类；其 `contract/` 目录集中定义 Conversation 协议（`conversation.ts`、`records.ts`、`snapshot.ts`、`slots.ts`、`input.ts`、`composer-blocks.ts`、`queue.ts`、`views.ts`），作为跨包契约。
- `ui-chat` 通过 `src/client/apply.ts` 调用 `ctx.uiConversation.binding(binding).target('chat')` 将自身挂载为名为 `chat` 的目标视图，并通过 `registerConversationNodes(ctx)` 注册消息、助手、工具、命令、压缩、重试、Turn 过程/尾部等业务节点定义，再调用 `registerChatNodeRenderers` 把 React 组件（`ChatView`、`MessageItem`、`AssistantMarkdown`、`TurnNavigator`、`StatsLine`、`DetailsPanel`、`ApprovalCommand` 等）挂到 `conversation.chat.node`、`conversation.message.images`、`conversation.approval.detail`、`details` 等槽位。
- 数据流方向：Session 事件 → `ConversationNodeAssembler` 增量匹配/合并 → 生成 `ConversationViewSnapshot` → 被 `ui-session` hooks 注入到各视图；Chat 侧额外维护 `stores.ts` 中的 `ChatStoreState` 管理选中节点与滚动位置。
- 依赖方向单向：`ui-chat` 依赖 `ui-conversation`（peerDependency + `@deepseek-ai/dsh-client-ui-conversation/client` 类型声明合并），`ui-conversation` 不反向依赖 `ui-chat`。
- 构建产物通过 `tsdown.config.ts` 输出 `lib/index.js`、`lib/client.js`、`lib/invariant.js` 及 `lib/types/**/*.d.ts`，并以 `dsh.client.inject` 声明运行时注入的 Cordis 服务。
