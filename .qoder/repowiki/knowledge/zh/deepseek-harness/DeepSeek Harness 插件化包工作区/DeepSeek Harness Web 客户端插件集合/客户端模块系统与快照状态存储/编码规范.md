- 通过 `package.json` 的 `exports` 字段同时暴露生产产物（`lib/*.js`）与源码（`./src/*`），使消费方既可用已编译版本也可按需引用源码。
- 对外 API 以 TypeScript 接口/类型声明为主，错误信息统一以 `client-modules:` 或 `[client-store]` 前缀开头，便于在日志中快速定位来源。
- Node 端通过 `ctx.effect` / `ctx.on` 订阅 cordis 生命周期并在构造时同步完成激活扫描，异步变更则通过 `queueMicrotask` 批量 flush。
- 浏览器端模块系统遵循懒 CJS 约定：脚本执行只做工厂注册（`window.__ModuleLoader__.load`），副作用延迟到首次 `materialize` 阶段，并以 `loadCache` 缓存结果。
- 状态更新统一通过 immer draft 的 `update(mutator)` 路径进行，`set` 仅在需要整体替换时使用，并在开发环境通过 `freeze` 深冻结以捕获意外变异。
- 持久化逻辑（localStorage）以可选方式挂载，读写失败仅记录警告而不破坏 store 运行，保证非浏览器环境与配额耗尽场景下的鲁棒性。
