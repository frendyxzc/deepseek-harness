模块由三个协作的包构成：
- `ui-settings` 是领域基座，通过 `src/client/settings-mirror.ts` 中的 `SettingsDescribeMirror` 集中维护一份 `settings.describe` 快照，订阅 `settings/document-updated` 与 `connection/reset` 事件刷新；`SettingsScopeBinder`（`settings-scope.ts`）暴露 `bind(spec)` 为每个命名空间创建 `SettingsScopeController`，封装原子 `mutate` 队列、revision fence、失败恢复与 `host/memory` 持久化模式；`schema.ts` 提供基于 `@deepseek-ai/schemastery` 的同步 schema 重水合、验证与不可变路径操作；所有能力以 Cordis Service 形式注入到宿主上下文。
- `ui-settings-general` 是 UI 壳层，`SettingsRoot.tsx` 通过 slot 机制渲染侧边栏触发器、模态面板与导航 rail，注册 `ui-onboarding` 命名空间并通过 `apply` 调用 Host 的 `settings.register` 完成 schema 注册；`shell-contract.ts` 定义 shell 与 sidebar 之间的 slot 契约，避免 ui-settings 反向依赖 ui-sidebar。
- `ui-settings-im` 是 IM 专属设置插件，`tdai-bots.ts` 中的 `TdaiBotsController` 消费 `feishu-bot` 命名空间的 `SettingsScope`，提供 `load/save` 视图与写入，UI 组件（`FeishuStatusTab`、`TdaiBotsEditor`）仅负责编辑与展示。
依赖方向严格单向：im/general → ui-settings（仅类型与 scope），ui-settings 不依赖任何 ui-* 呈现包，从而避免 ui-sidebar → ui-layout → ui-theme 的循环引用。构建产物通过 `tsdown.config.ts` 输出至 `lib/`，并以 `dsh.client.inject` 声明运行时注入项。
