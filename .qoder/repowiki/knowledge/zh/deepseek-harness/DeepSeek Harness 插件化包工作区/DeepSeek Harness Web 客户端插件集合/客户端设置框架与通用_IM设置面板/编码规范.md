- 通过 Cordis Service 暴露跨插件能力（如 `SettingsScopeBinder`、`SettingsSchemaService`），并在 `Context` 接口上扩展对应字段名，使消费者通过 `ctx.get('...')` 获取而非直接导入。
- 所有可观察状态统一使用 `createSnapshotStore` 提供的 `getSnapshot/subscribe` 模式，保证快照引用稳定且变更可追踪。
- 命名空间通过字符串常量（如 `ONBOARDING_SETTINGS_NAMESPACE`、`FEISHU_BOT_SETTINGS_NAMESPACE`）集中声明，并在 Host 侧 `apply` 中用 `settingsNamespace` + schemastery schema 注册。
- 写路径采用 revision fence + 队列尾（`tail` Promise）串行化，失败时回退到 `mirror.load()` 恢复最新文档，避免并发写冲突。
- UI 壳层通过 slot 契约（`renderSlot('settings.*', ...)`）解耦内容注册与渲染，Shell 只持有布局与导航逻辑，具体 section/onboarding 步骤由外部插件贡献。
- 通过 type-only import 引入 `@deepseek-ai/dsh-api-remotes/types` 等仅类型依赖，避免将 Host 生成的 `/remote` 产物拖入浏览器构建图造成死锁。
