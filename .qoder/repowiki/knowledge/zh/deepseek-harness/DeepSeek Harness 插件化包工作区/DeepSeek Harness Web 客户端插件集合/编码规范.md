- 每个功能域一个独立插件包，通过 `ctx.slots.register` 声明 slot 并仅使用 props 四共享（Runtime/RenderSlots/Store/inject）接收数据，组件不直接访问 ctx。
- 跨插件协作只能通过 Cordis service inject 或 slot 传递 JSON 兼容数据与回调，禁止运行时 import/re-export 其他插件的值。
- 共享状态以 `createXXXStore()` 工厂形式在 register 处声明，组件通过 `props.useStore` 读取、`props.actions.*` 写入。
- 构建产物由 `tsdown.config.ts` 调用 `clientBundle(id, libEntry)` 生成，Node 半包与浏览器 bundle 同时产出，CSS Modules 经 lightningcss 内联。
- 包清单中的 `dsh.client.external` 仅用于请求模块表条目，非 baseline 的 `@deepseek-ai/*` 导入会被构建期纯度门拒绝。
- 测试位于包内 `tests/`，通过相对路径直接 import 源码内部实现，不为了测试而扩大公共导出。
