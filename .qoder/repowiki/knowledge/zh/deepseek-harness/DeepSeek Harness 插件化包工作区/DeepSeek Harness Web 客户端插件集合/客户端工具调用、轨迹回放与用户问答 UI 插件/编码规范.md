- 每个包采用双入口结构：根 `src/index.ts` 仅导出空 `apply()` 作为宿主加载桩，浏览器侧行为统一放在 `src/client/index.ts` 并通过 `inject` 数组声明所需服务。
- 通过 `package.json` 的 `dsh.client.inject` 声明插件依赖的服务列表，并在 `apply(ctx)` 中以 `ctx.get('...')` 或类型断言方式获取，保持插件对宿主能力的弱耦合。
- 本地化文案集中定义在 `locales.ts`（或 `locale.ts`），通过 `ctx.locale.register(NS, { zh, en })` 注册命名空间，并使用 `ctx.locale.bind(NS)` 生成带作用域的翻译函数。
- 对外暴露的类型通过 `declare module '@deepseek-ai/dsh-client-ui-slots'` 等方式扩展框架 SlotMap/Props 接口，使自定义 slot 与 props 具备完整类型推导。
- 可插拔的视图组件以独立文件形式实现并通过 `ctx.plugin(...)` 动态注册（如 ui-tool 中的各类 toolview、ui-trajectory 中的各 definition 注册器），避免主入口硬编码所有渲染分支。
- 异步交互生命周期通过类封装（如 `PendingQuestion`、`TrajectoryDurationStore`），提供 answer/cancel/abort/delegate 等方法并以 Promise.withResolvers 管理结果与错误传播。
