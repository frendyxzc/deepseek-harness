本目录是 DeepSeek Harness Web 客户端的插件仓库，每个子目录是一个独立的 `@deepseek-ai/dsh-client-*` 包，遵循同一套契约：
- 统一注册入口：各插件在 `src/client/index.ts` 暴露 `apply`/`inject`，通过 `ctx.slots.register({ name, children?, store?, inject? }, Component)` 把 UI 注入到由 `ui-renderer` 渲染的 slot 树中，只有 `root` 由 shell 直接渲染。
- 分层依赖：数据对象层（`connection`、`store`）→ 渲染层（`ui-renderer`、`ui-slots`）→ 展示组件（各业务插件），单向引用，禁止跨插件运行时值导入。
- 模块图与 DI 分离：Cordis service `inject` 用于运行时服务装配；`dsh.client.external` + `web/src/platform.ts` 的 `PLATFORM_MODULES` 声明动态模块表条目，由 `tsdown.client.ts` 的 `clientBundle` 预设生成 `window.__ModuleLoader__.load` 包裹的 CJS 工厂，按拓扑序加载。
- 构建面：每个插件同时产出 Node 半包（`lib/types/*`）和浏览器 bundle（`lib/client.js`），CSS Modules 经 lightningcss 内联并注入带 `data-plugin` 标记的 `<style>` 标签。
- 装配编排：`packages/bundle/web-app/cordis.patch.yml` 与 `package.json` 共同声明插件清单，`web` 包作为启动内核加载 React/Cordis/静态库并通过 Loader 拉取动态插件。
