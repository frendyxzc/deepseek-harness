- 每个包采用双入口模式：根 `src/index.ts` 仅导出空 `apply()` 占位宿主桩，浏览器侧逻辑集中在 `src/client/index.ts` 并通过 `package.json` 的 `exports["./client"]` 暴露。
- 通过 `declare module '@deepseek-ai/cordis' { interface Context { ... } }` 扩展 Context 接口（如 `commandUi`、`inputTriggers`），并以 `inject = [...]` 数组声明运行时依赖的服务名。
- 通过 `declare module 'dsh-client-ui-slots' { interface LocaleNamespaceMap { ... } }` 合并 locale 命名空间，并使用常量 `NS`/`MENU_NS` 集中管理字典键前缀。
- UI 组件通过 `ctx.slots.inject('<slot>', () => ctx.slots.register({ name, id, order, locale, inject }, View))` 的方式按固定 order 值（overlay: 0/1，dock: 10）注入到宿主插槽。
- 服务类继承自 `@deepseek-ai/cordis` 的 `Service`，内部可变状态集中在一个 `LiveState` 对象中，并通过 `ctx.effect(() => ..., 'label')` 注册带清理函数的副作用。
- 所有对外暴露的持久化变更（GoalBar 的 edit/pause/resume/clear、Command 的 execute）都先通过 `sessions.binding(...).projections.faceOf(...).getSnapshot()` 读取当前 CAS 引用再调用 Remote 方法，避免状态不一致。
