- 每个插件采用 Host/Browser 双入口模式：`src/index.ts` 暴露 `name`、`inject`、`Config` 与 `apply(ctx, config)`，`src/client/index.ts` 提供浏览器侧逻辑并通过 `ctx.provide` 注入服务。
- 插件配置统一通过 `schemastery` 的 `z.object({...}).default(...)` 定义 `Config` 接口与同名常量，在 `apply` 入口处消费默认值。
- 对外暴露的类型集中在各自 `src/index.ts` 顶部通过 `export type { ... }` 显式 re-export，内部实现类型保持私有。
- 错误与不变量通过独立的 `invariant.ts` 文件集中处理，避免在业务逻辑中散落断言。
- 可观察状态以不可变快照（`Object.freeze`）+ 监听器集合的形式发布变更，并提供 `getSnapshot`/`subscribe` 双接口供 React hooks 等消费。
- 插件通过 `ctx.effect` 注册副作用并在返回的清理函数中释放资源（定时器、EventSource、route 等），确保上下文销毁时自动回收。
