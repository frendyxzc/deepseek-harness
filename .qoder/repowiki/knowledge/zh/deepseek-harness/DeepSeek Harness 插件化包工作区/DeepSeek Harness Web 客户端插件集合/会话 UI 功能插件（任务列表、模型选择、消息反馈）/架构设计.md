本模块由三个并列的 npm 包组成：`@deepseek-ai/dsh-client-ui-jobs`、`@deepseek-ai/dsh-client-ui-model-selection`、`@deepseek-ai/dsh-client-ui-message-feedback`。每个包遵循统一结构：顶层 `src/index.ts` 暴露空 `apply()` 作为 Node 端占位插件体，使包在宿主 cordis.yml / Loader 中可见；真正的浏览器侧行为通过 `package.json` 的 `exports["./client"]` 与 `dsh.client.inject` 声明被宿主发现并挂载到 `ClientContext`。各包的 `src/client/index.ts` 是插件入口，通过 `ctx.locale.register(NS, { zh, en })` 注册本地化命名空间，再通过 `ctx.slots.inject(...)` 将 React 组件注入到对话界面的特定插槽（如 `conversation.session.header.actions`、`conversation.input.model`、`conversation.chat.assistant-actions`），并以 `order` 控制渲染顺序。`ui-model-selection` 额外维护一个跨命令与座位共享的 `ModelDirectoryResolver` 服务，把 `/model` 命令的 popupSelect 与 composer 的 `conversation.input.model` 座位绑定到同一目录 store，并通过 `session.selectModel` 提交变更。`ui-message-feedback` 按 SessionId 缓存 `MessageFeedbackController` 实例，监听 `connection/reset` 事件触发 resync。每个包还提供一个 `invariant.ts` 作为 `@deepseek-ai/dsh-invariants` 的 companion，用 `ctx.invariants.register(PACKAGE_NAME, install)` 声明自身无运行时不变量，以证明 HMR 安全。构建统一使用 `tsdown`，产物输出到 `lib/`，并通过 `files` 字段仅发布 `lib/index.js`、`lib/invariant.js`、`lib/client.js` 及类型声明。
