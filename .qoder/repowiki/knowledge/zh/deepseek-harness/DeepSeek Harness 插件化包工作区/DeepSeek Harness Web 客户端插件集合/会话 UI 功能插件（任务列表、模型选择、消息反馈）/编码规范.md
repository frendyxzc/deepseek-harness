- 每个包同时导出空的 Node 端 `apply()` 与浏览器端 `src/client/index.ts`，后者通过 `inject` 数组声明所需服务并在 `apply(ctx)` 中完成插槽注册与本地化字典挂载。
- 本地化文案通过定义 `NS` 常量并使用 `ctx.locale.register(NS, { zh, en })` 注册，同时在 `src/client/index.ts` 中通过 `declare module '@deepseek-ai/dsh-client-ui-slots'` 扩展 `LocaleNamespaceMap` 以提供类型化的翻译键。
- 通过 `ctx.slots.inject(slotName, () => ctx.slots.register({...}, Component))` 模式将 React 组件注入到宿主定义的插槽，并用 `order` 字段控制渲染次序。
- 每个包提供独立的 `invariant.ts`，以 `ctx.invariants.register(PACKAGE_NAME, install)` 形式向 `@deepseek-ai/dsh-invariants` 声明自身无运行时不变量，用于 HMR 安全验证。
- 包内测试文件统一位于 `tests/` 目录下，命名采用 `<feature>.client.spec.(ts|tsx)` 约定，覆盖插槽、控制器与样式等维度。
- 构建配置统一使用 `tsdown.config.ts`，`package.json` 的 `files` 字段仅发布 `lib/index.js`、`lib/invariant.js`、`lib/client.js` 及 `lib/types/**/*.d.ts`，保持产物最小化。
