本模块由两个顶层目录组成：`packages/examples/agent-spine-demo` 是一个 Cordis 插件式 Agent 骨架，通过 `apply(ctx, config)` 按依赖顺序挂载 LLM、Session、SystemPrompt、ToolRuntime、SkillRegistry、GoalService、LocalJobRegistry、InvariantRegistry、toolBash/toolJobs、AgentLoop 等子插件，并以 schemastery schema 对外暴露组合后的 `Config`；`packages/test-support/` 下每个子包均为独立 npm 包（均声明 `type: module`、`main: lib/index.js`、`exports` 同时导出 `./invariant`），职责划分清晰——`client-runtime` 在 jsdom + React Testing Library 中组装真实 SlotRegistry/Renderer 并提供 `SlotTestRuntime`/`TestRoot`/`TestSessions`/`TestWorkspaces` 双测环境；`session-snapshot` 基于 ACP 协议实现 `launchAcpTestAgent`/`runScenario`/`defineAcpSnapshotSuite` 及 stdout/session-log/workspace 的归一化与快照比对；`llm-mock-server` 用 Node `http` 实现 OpenAI `/chat/completions` SSE 行为脚本服务器，支持 `sequence`/`random`/`repeatLast` 等配置；`llm-replay` 作为 LLM 插件短路流式输出以回放 JSONL 会话；`loader-smoke` 提供 subprocess 与直接 agent 执行 harness；`agent-loop-testkit` 为具体 agent loop 测试提供前置挂载。各包之间通过 workspace 依赖引用核心 dsh 包，彼此不互相依赖，仅被上层测试用例消费。
