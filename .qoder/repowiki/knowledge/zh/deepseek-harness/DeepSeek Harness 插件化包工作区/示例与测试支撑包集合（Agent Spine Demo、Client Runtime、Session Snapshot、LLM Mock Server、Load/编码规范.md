- 每个子包采用 src/lib 双目录结构，源码位于 `src/`，构建产物位于 `lib/`，并通过 `package.json` 的 `exports` 字段同时暴露根入口与 `./invariant` 子路径。
- 所有 test-support 包将核心依赖声明为 `peerDependencies`（workspace:^），自身仅保留测试与构建期依赖，避免重复安装 Cordis/dsh-* 运行时。
- 对外 API 通过命名导出（函数/类/接口/schema）而非默认导出，便于消费者按需引入且不被打包器扁平化丢弃类型。
- 配置对象使用 schemastery `z.object(...).intersect(...)` 组合子插件 Config，并配套导出对应的 TypeScript 接口与 `pickSpineConfig` 白名单裁剪函数。
- 测试数据以 fixtures 目录 + YAML/JSONL snapshot 形式存放，配合 normalize/scrub 工具对 session id、系统提示、工具 schema 等不稳定字段进行稳定化处理后再断言。
- 错误与不变量检查集中在同包的 `invariant.ts` 中，并通过 `./invariant` 子路径单独导出，供调用方做运行时守卫。
