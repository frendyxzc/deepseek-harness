文档按主题划分为多个子目录：顶层为概览性文档（architecture、module-graph、glossary、testing、development 等）；`subsystems/` 以每个子系统为单位提供中英双语说明；`cordis-api/` 与 `cordis-tutorial/` 分别描述 Cordis 插件框架的 API 与分步教程；`user/` 面向使用者，分为 `guide/`（使用指南）和 `develop/`（开发者实践，含 basic/framework/practice 三级结构）；`cookbook/` 收录扩展开发示例；`postmortem/` 记录事故复盘；`i18n/` 定义双语配对规范、术语表与翻译规则。每个文档采用三文件配对模式：`foo.md`（英文）、`foo.zh.md`（中文）、`foo.i18n.yaml`（记录双方最新确认内容的 git blob hash），由 `verify-translation-pairing` 门禁强制校验结构签名与哈希一致性，并通过 Git merge driver 在合并时自动组合配对记录。生成式文档（如 subsystem-region 生成器）将配对路径投影到各语言输出，但保持非技术内容字节一致。
