`pnpm build` 调用 `vite build` 产出 `dist/assets/*`；`pnpm dev` 启动开发服务器；`pnpm build:preview` 先 tsdown 编译 webworker runtime/packer，再构建并把 bootstrap chunk 注入 `dist/preview.html`，同时生成 `dist/preview/vfs-image.tar.gz`；`pnpm serve:preview` 用 http-server 在 4173 端口静态托管 preview 页面；E2E 通过 `$DSH_SNAPSHOT=replay|record|refresh` 切换回放/录制/刷新模式，record 模式需要 `DEEPSEEK_API_KEY`。
