`scripts/setup-dsh/setup.sh` 是一键本地环境引导入口，支持 `--dsh-home`、`--workspace`、`--branch`、`--skip-memory`、`--skip-install`、`--upgrade`、`--force`、`--non-interactive` 等参数；通过 `DSH_*` 环境变量注入密钥（如 `DSH_PROXY_USER_KEY`、`DSH_DEEPSEEK_API_KEY`、`DSH_TDAI_LLM_API_KEY`）。CI/本地门禁统一通过 `pnpm run check:ci:*` 或 `pnpm run run-gates <mode>` 触发，其中 `run-gates` 支持 `ci-primary`、`ci-coverage`、`ci-snapshot`、`ci-consumers`、`node-compat`、`check-all`、`hygiene`、`doc-sync`、`doc-quick` 等模式，并由 `DSH_GATE_CONCURRENCY`、`DSH_COVERAGE_MAX_WORKERS`、`DSH_WEB_SNAPSHOT_WORKERS` 等环境变量调节并发。
