模块由两部分组成：`gitlab-mr-poller.mjs` 是 DSH cordis 函数插件（export `name='gitlab-mr'`、`inject=['tools','agents']`），在 `apply(ctx, rawConfig)` 中注册 `gitlab_watch_mr` ToolDefinition，并通过 `setInterval` 按 `pollIntervalMs` 轮询已登记 MR 的新评论与 merged/closed 状态变化，使用 `agent.followup()` 将事件注入回创建该 MR 的会话；`gitlab-mr-workflow/SKILL.md` 是 Agent 出站 SOP，约定 git/glab 命令、MR 创建后必须调用登记工具、回复评论与合并沉淀流程。依赖方向单向：Skill 指导 agent 调用插件暴露的工具，插件通过 `ctx.get('credentials')` 解析 token、通过 `ctx.agents` 查找会话、通过 `ctx.tools.register` 注册工具，不 import 任何 `@deepseek-ai` 包，仅依赖 Node 全局与 `node:fs/node:path/node:crypto`。持久化采用进程外 JSON 文件（默认 `.dsh-gitlab-mr-state.json`，相对 `$DSH_HOME`）保存 `{tracked: {projectKey: {iid: {lastNoteId, state, sessionId}}}}`，支持重启恢复游标与会话绑定。
