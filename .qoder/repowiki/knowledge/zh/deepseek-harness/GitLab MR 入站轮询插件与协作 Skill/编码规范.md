- 插件以 ESM 模块形式 export `name`、`inject`、`apply(ctx, rawConfig)`，遵循 DSH cordis 函数插件契约。
- 配置通过 `DEFAULTS` 对象合并原始配置，并对必填字段（如 `botUsername`）与数值范围进行校验与归一化。
- Token 优先从 `ctx.credentials.resolve(tokenEnv)` 解析，失败时回退到同名环境变量，永不写入配置文件。
- 对外部 API 调用统一封装为 `glFetch`，附加 `PRIVATE-TOKEN` 与自定义 `user-agent`，并将非 2xx 响应包装为带 `status` 的错误。
- 状态变更通过 `loadState`/`saveState` 读写 JSON 文件，并以 `changed` 标志仅在必要时落盘，避免频繁 IO。
- 事件过滤采用「水位线 + 白名单」模式：记录 `lastNoteId` 作为游标，仅投递 id 大于游标且非 bot 作者、非 system 的新评论。
