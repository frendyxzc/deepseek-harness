模块以 `src/bin.ts` 为唯一可执行入口（通过 `package.json#bin` 暴露 `dsh`），使用 Commander 在 `src/args.ts` 中把 argv 解析为三种互斥的 `DshInvocation`（`profile` / `plugin` / `dump-config`），再基于 `mode` 字段动态 `import()` 对应处理器：`profile-boot.ts` 负责加载 Cordis profile、拼接 bundle → profile.patch.yml → $DSH_HOME/cordis.patch.yml → --patch 覆盖层并注入 DSH_TELEMETRY_DISABLED 开关，随后调用 `@deepseek-ai/dsh-app-boot.boot` 挂载应用树并提供 cmdline/ready/shutdown 服务；`plugin.ts` 作为 pnpm 转发器，在 profile 目录执行 `pnpm <args>` 后根据已安装包是否声明 `dsh.bundle` 自动同步 `dsh.profile.bundles` 列表；`dump-config.ts` 复用同一套 patch 组合逻辑但不启动任何 entry，仅输出分层注释。构建由 `tsdown.config.ts` 指定 `lib/types/bin.js` 为入口打包 ESM，源码经 tsc 编译到 `lib/`，测试位于 `tests/` 下含大量 e2e 用例与 fixtures。依赖方向单向：bin → args → 各 mode handler → 外部 workspace 包（`@deepseek-ai/dsh-*`），模块内部无循环。
