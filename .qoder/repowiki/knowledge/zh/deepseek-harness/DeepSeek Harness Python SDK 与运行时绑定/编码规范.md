- 配置类统一使用 `@dataclass(slots=True)` 定义（如 `DeepSeekHarnessConfig`、`HarnessConfig`），并通过 `field(default_factory=...)` 提供可变默认值。
- JSON-RPC 请求-响应通过 `uuid.uuid4()` 生成字符串 id，并以 `queue.Queue` 作为 waiter 进行一对一匹配，异常通过向同一 queue 放入 `BaseException` 传播。
- 通知订阅采用“订阅 ID + 过滤器函数”模式，`subscribe_notifications` 返回 `NotificationSubscription` 上下文管理器，自动在退出时注销。
- 所有面向用户的入口类（`DeepSeekHarness`、`HarnessClient`、`NotificationSubscription`）均实现 `__enter__`/`__exit__` 以支持 with 语句管理生命周期。
- 运行时定位失败统一抛出带有获取指引的 `FileNotFoundError`，并通过 `_EXE_ACQUISITION_HINT` 常量复用相同的诊断文案。
- 消息体使用 Pydantic `BaseModel` 进行强类型校验（如 `InitializeResponse`、`_SessionPromptResponse`、`_ShutdownResponse`），客户端在反序列化前对返回值做 dict 类型断言。
