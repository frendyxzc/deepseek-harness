模块以 VitePress 为核心，入口为 `.vitepress/config.ts`，通过 `withMermaid` 包装配置，定义 `root`（简体中文）与 `en`（English）两套 locale，各自挂载 Guide/Develop/Reference 三个导航模块。

- 内容编排集中在 `docs.ts`：声明式列出所有页面（`homeAndGuide`、`develop`、`cordisTutorial`、`subsystemsReference`、`reference`），使用 `pairedPages` / `mirroredPages` 辅助函数把同一份源映射到两个 locale，并通过 `DocsSidebar` 类型（`zh-guide`、`zh-develop`、`zh-reference`、`en-*`）组织侧边栏分组与折叠状态。
- 构建时由 `build.ts` 调用 `vitepress build`，并在 `onAfterConfigResolve` 中执行 `cleanDocSiteOutput` 安全清理输出目录；开发时通过自定义 Vite 插件监听上游 `docsSourceFiles()` 变更并重新 `projectDocs()`，同时提供中间件在运行时服务原始 Markdown 与 `llms.txt`。
- 依赖外部脚本 `../../scripts/project-doc-site.ts` 完成 Markdown 投影（生成 `.generated` 源码树）、原始文件同步与 `llmsTxt` 索引生成，使文档源始终位于其所属仓库层级而非复制进本目录。
- 主题样式以内联 CSS/JS 注入（wordmark SVG、滚动条脚本、Vue 插值转义），搜索、编辑链接、社交链接等通过 `sharedTheme` 共享。
