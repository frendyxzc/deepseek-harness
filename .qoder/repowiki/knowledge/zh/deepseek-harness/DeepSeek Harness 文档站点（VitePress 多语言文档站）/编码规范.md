- 新增文档页通过在 `docs.ts` 中以 `pairedPages` / `mirroredPages` 声明式注册，统一指定 source、route、label、sidebar、section、order，避免手写路由表。
- 中英双语通过 `localeCollections` 与 `sections` 集中声明，侧边栏分组顺序与折叠行为由 locale 维度的数组驱动，新增分组需同时出现在两处。
- 导航项与侧边栏均通过 `orderedPages` + `sectionSpec` 排序派生，禁止硬编码链接，确保重命名或重排后导航仍指向首篇。
- 构建脚本对输出目录执行路径白名单校验（`escapesRoot` + `realpathSync`），防止符号链接或相对路径逃逸站点根。
- Markdown 渲染器规则在 `markdown.config` 中统一拦截 text/code_inline/fence，对 Vue 插值做转义并对 mermaid/带 src 的代码块放行。
